Before you paste:

  • • Enable pg_cron on your database.
  • • Enable pg_stat_statements on your database (for query-level analysis).
  • • Each bundle is wrapped in BEGIN; … COMMIT;. If something fails, nothing partial gets installed.

After install, run SELECT * FROM pgfr_record.health_check(); to verify the recorder is collecting. See the project page for daily-monitoring and incident-response workflows.
